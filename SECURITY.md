# Politique de Sécurité

## Signalement d'une vulnérabilité

Si vous identifiez une faille de sécurité dans ce dépôt (exposition de données, erreur de configuration de workflow ou faille dans les scripts), merci de ne pas ouvrir d'issue publique contenant des détails exploitables.

Utilisez l'onglet **Security > Advisories > Report a vulnerability** de ce dépôt GitHub pour transmettre un signalement privé.
